1

Why $dp[0] = 1$?

$dp[0]$ represents an empty string. There is exactly 1 way to decode an empty string (doing nothing). If we encounter a valid 2-digit number (like "26") at the start, $dp[2] += dp[0]$ adds this single way (26 $\rightarrow$ Z), making the transition logic uniform.

2

Handling Zeros ('0')

A standalone '0' cannot map to any letter. Thus, if `oneDigit` is 0, we add 0 ways (skip $dp[i-1]$ transition). A '0' can only survive if combined with '1' or '2' to form "10" or "20". This is why $dp$ arrays are incredibly effective at dealing with zeros.

3

Optimal DP State

For any position $i$, the number of ways to decode is simply the sum of translating the last single digit (if valid, adding $dp[i-1]$) and the last double digit (if valid, adding $dp[i-2]$). This mirrors the Fibonacci sequence but with conditional validation constraints!
